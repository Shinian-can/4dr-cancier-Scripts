## <span id="fanqienovelPlus">番茄小说网页阅读增强</span>

在https://fanqienovel.com/reader/的所有子网站右下角加入了悬浮球。

只在edge上测试过。

###### 功能

1，可以设置阅读区域宽度，文字左右边距，以及文字颜色，小说背景，外部背景的颜色。

2，设置好之后下次进入自动恢复上次设置的偏好。

3，底部的重置默认按钮，点击后恢复网页原本的所有设置。

###### 关于悬浮球

1，拖动以变换位置

2，点击即可进入阅读增强设置界面
