## 番茄小说网页阅读增强

在 `fanqienovel.com/reader/` 所有子页面右下角添加悬浮球入口。

> 目前仅在 **Edge 浏览器** 上测试通过。

### 主要功能

- **阅读区域宽度调节**：自由调整阅读区域宽度（50% ~ 100%）
- **文字左右边距调节**：调整文字与边界的距离（0 ~ 100px）
- **颜色自定义**：支持修改文字颜色、小说背景、外部背景颜色
- **自动保存偏好**：设置后自动保存，下次打开自动恢复
- **一键重置**：点击「重置默认」恢复网页原始设置

### 悬浮球操作

- **拖动**：按住悬浮球拖拽可改变位置
- **点击**：单击打开阅读增强设置面板


## 安装使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）浏览器扩展
2. 点击脚本链接安装，或手动导入 `.js` 文件
3. 刷新目标页面，右下角出现 `C` 悬浮球即表示加载成功
